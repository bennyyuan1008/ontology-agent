### R1 盲测第 6 条的特殊案例（黄金集缺陷 vs 语义正确）

- 用例："目前库存最多的商品是什么"
- 发现：**黄金集本身错了**——数据含 3 行 QTY=NULL，Oracle `ORDER BY QTY DESC` 默认 **NULLS FIRST**（DESC 时），黄金 SQL 取到 NULL
- 处理：修复引擎（统一 `NULLS LAST`）→ 重新生成黄金 → 黄金结果 = 223907（正确）
- agent 用 `MAX(QTY)` 聚合天然正确（223907），但**实现路径与黄金（点查排序）不同** → 严格对比记 ❌，语义正确
- 结论：严格口径 6/7=86%；实质正确 7/7=100%。**黄金集与评测器（结构严格对比）的局限已记录，下一轮可考虑"结果包含预期值"判定**
